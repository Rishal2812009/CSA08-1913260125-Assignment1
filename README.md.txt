## Assignment Objective

This repository contains the implementation, testing and analysis of a milk payment calculator for Ksheera Village Milk Producers’ Co-operative.

The calculator computes farmer payments based on:

- litres of milk,
- fat percentage,
- SNF percentage,

and ensures that every payment is correct to the paisa.
